# Exemples de prompts

## Optimisation LinkedIn

```text
Utilise la skill linkedin-profile-optimizer.
Objectif : renforcer mon positionnement d’Architecte IT orienté plateformes d’intégration, cloud et gouvernance.
Voici mon headline actuel : [...]
Voici ma section About : [...]
Contraintes : ne rien inventer, signaler les informations à compléter.
```

## Extraction de réalisations

```text
Utilise la skill achievement-extractor.
Transforme ces notes projet en bullets CV orientées impact.
Notes : [...]
Format attendu : STAR + version CV concise.
```

## Contenu LinkedIn

```text
Utilise la skill thought-leadership-generator.
Sujet : gouvernance des plateformes d’intégration dans une grande entreprise.
Audience : DSI, Enterprise Architects, responsables plateformes.
Ton : sobre, utile, non promotionnel.
```
## Veille technologique

```text
Utilise la skill technology-watch.
Sujet : évolution des plateformes d’API Management et d’intégration cloud.
Audience : DSI et architectes d’entreprise.
Format attendu : synthèse exécutive + recommandations d’action.
Contraintes : ne rien inventer, citer les sources, séparer faits et analyse.
```

## Gouvernance IA

```text
Utilise la skill ai-governance.
Objectif : proposer un cadre de gouvernance IA générative pour une grande entreprise.
Audience : DSI, RSSI, DPO, juridique et métiers.
Format attendu : principes, RACI, processus de qualification, grille de risques, roadmap 30/60/90 jours.
Contraintes : ne rien inventer, distinguer recommandations et obligations réglementaires vérifiées.
```

## Photo de profil LinkedIn

```text
Utilise la skill linkedin-profile-photo-prompt.
Objectif : obtenir une photo de profil LinkedIn cohérente avec un positionnement d’Architecte IT.
Audience : recruteurs, DSI et architectes d’entreprise.
Point de départ : retouche d’une photo existante.
Apparence réelle : lunettes à monture fine, barbe courte, cheveux courts châtains, chemise unie.
Générateur visé : Gemini.
Format attendu : 3 variantes de prompt, 1 prompt de retouche, 1 prompt de bannière.
Contraintes : ne rien inventer sur mon apparence, aucun logo, aucun décor trompeur.
```

## Orientation

```text
Utilise la skill career-skills-router.
Je veux préparer un changement de poste dans les 6 mois.
J'ai un CV à jour, un profil LinkedIn négligé, et rien d'écrit sur mes projets.
```

## Préparation d’entretien

```text
Utilise la skill interview-preparation.
Type d'entretien : hiring manager, 45 minutes, visio.
Offre : [coller l'offre]
Mon parcours : [coller le CV]
Point sensible : 8 mois sans emploi entre mes deux derniers postes.
Contraintes : ne rien inventer, réponses orales de moins de deux minutes.
```

## Négociation salariale

```text
Utilise la skill salary-negotiation.
Situation : proposition d'embauche reçue, poste actuel tenable.
Package actuel : [fixe, variable réel, participation, télétravail]
Proposition reçue : [détail composant par composant]
Benchmarks dont je dispose : aucun.
Contraintes : n'invente aucune donnée de marché, traite le package complet.
```

## Message d’approche

```text
Utilise la skill networking-outreach.
Destinataire : responsable plateforme dans une entreprise cible.
Lien réel : j'ai assisté à sa présentation lors d'un meetup en mars.
Objectif : obtenir un échange de 20 minutes, pas candidater.
Canal : message LinkedIn.
Contraintes : n'invente aucun point commun, une seule demande.
```

## Réponse à un appel à conférenciers

```text
Utilise la skill call-for-papers-responder.
Événement : [nom, audience, format, niveau, langue, date limite]
Champs du formulaire : titre 80 caractères, abstract 1200 caractères, bio 400 caractères.
Sujet envisagé : retour d'expérience sur une migration de socle d'intégration.
Contraintes : n'annonce que ce que je peux livrer, signale les risques de refus.
```
