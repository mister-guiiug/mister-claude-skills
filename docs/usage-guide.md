# Guide d’usage

## Choisir la bonne skill

- Profil LinkedIn : `linkedin-profile-optimizer`
- Positionnement senior : `executive-personal-branding`
- Réalisations CV : `achievement-extractor`
- Posts LinkedIn : `thought-leadership-generator`
- Récit projet IT : `architecture-storytelling-expert`
- Conférence : `conference-speaker-coach`
- CV : `cv-optimizer`
- Message exécutif : `executive-content-writer`
- Relecture recruteur : `recruiter-perspective-reviewer`
- Évolution carrière architecte : `it-architect-career-advisor`
- Veille technologique : `technology-watch`
- Gouvernance IA : `ai-governance`
- Photo de profil et bannière LinkedIn : `linkedin-profile-photo-prompt`

## Enchaînements utiles

| Objectif | Enchaînement de skills |
| --- | --- |
| Refonte complète du profil LinkedIn | `achievement-extractor`, puis `linkedin-profile-optimizer`, puis `recruiter-perspective-reviewer`, puis `linkedin-profile-photo-prompt` |
| Candidature ciblée | `cv-optimizer`, puis `recruiter-perspective-reviewer` |
| Prise de parole publique | `technology-watch`, puis `thought-leadership-generator`, puis `conference-speaker-coach` |
| Valorisation d’un projet | `architecture-storytelling-expert`, puis `executive-content-writer` |

## Bonnes pratiques

1. Fournir des faits bruts.
2. Indiquer l’audience cible.
3. Préciser le niveau de confidentialité.
4. Demander une version courte et une version détaillée.
5. Relire les chiffres, dates et responsabilités avant publication.
