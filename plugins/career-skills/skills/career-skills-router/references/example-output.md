# Exemple de sortie

Exemple fictif produit à des fins d’illustration.

## Demande reçue

```text
Je veux être plus visible dans mon domaine, je ne sais pas par où commencer.
```

## Questions posées, deux maximum

1. Cette visibilité sert-elle un objectif précis à court terme, changer de poste, être sollicité pour des conférences, peser en interne ?
2. Disposez-vous déjà de matière, projets vécus, notes, mesures, ou faut-il partir de zéro ?

## Réponse de l’utilisateur

```text
Objectif : être sollicité pour des postes d'architecte d'entreprise d'ici un an.
Matière : oui, plusieurs programmes conduits, mais rien d'écrit.
```

## Orientation proposée

Objectif réel reformulé : se rendre identifiable comme candidat crédible sur des postes d’architecte d’entreprise, dans un horizon de 12 mois. La visibilité est un moyen, pas la finalité.

Enchaînement retenu :

| Ordre | Skill | Raison |
| --- | --- | --- |
| 1 | `achievement-extractor` | Rien n’est écrit, la matière doit exister avant toute mise en forme |
| 2 | `executive-personal-branding` | Fixer le positionnement avant de produire du contenu, sinon les publications partent dans plusieurs directions |
| 3 | `linkedin-profile-optimizer` | Le profil est le premier point de contact d’un recruteur |
| 4 | `thought-leadership-generator` | Produire des angles alignés sur le positionnement |
| 5 | `recruiter-perspective-reviewer` | Vérifier ce que voit réellement un recruteur avant d’accélérer |

Skills écartées pour l’instant :

- `executive-content-writer`, utile seulement une fois les angles définis.
- `it-architect-career-advisor`, pertinent si le choix de trajectoire était encore ouvert, ce qui n’est pas le cas ici.

## Matière à réunir avant de démarrer

- 3 à 5 programmes conduits, avec périmètre, décisions et mesures si elles existent.
- 3 offres d’architecte d’entreprise qui vous intéressent réellement.
- Le profil LinkedIn actuel.

## Première étape

Je démarre avec `achievement-extractor` sur le premier programme. Décrivez-le librement, même sans structure, y compris ce qui n’a pas fonctionné.
