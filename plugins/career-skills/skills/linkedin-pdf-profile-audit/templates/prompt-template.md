# Prompt template - LinkedIn PDF Profile Audit

Utilise la skill `linkedin-pdf-profile-audit`.

Fichier : [joindre l’export PDF du profil, souvent nommé Profile.pdf]

Qui est audité et pourquoi : [mon profil, un profil que j’accompagne, une candidature que j’évalue, plusieurs profils à comparer]

Rôle cible : [ex. Enterprise Architect, Lead Integration Architect]
Audience visée : [recruteurs, DSI, COMEX, pairs techniques]
Langue du profil : [français, anglais, les deux]

Offres cibles :
- [coller 3 à 5 offres, ou indiquer aucune]

Éléments non visibles dans l’export, que je peux te donner :
- URL du profil : [à compléter]
- Mention Open to work active : [oui ou non]
- Nombre de recommandations reçues : [à compléter]
- Section Sélection ou Featured renseignée : [oui ou non, contenu]
- Publications récentes : [fréquence, sujets, ou aucune]

Contraintes :
- Ne rien inventer, en particulier sur les trous de parcours.
- Déclare d’abord ce que l’export ne te permet pas de voir.
- Cite l’élément précis du PDF pour chaque constat.
- Limite les priorités P1 à cinq.
- Fournis les reformulations en avant et après, directement copiables.
- Termine par une première action réalisable aujourd’hui.
