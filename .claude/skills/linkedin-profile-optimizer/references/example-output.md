# Exemple de sortie

Exemple fictif produit à des fins d’illustration. Les données ne correspondent à aucune personne ni organisation réelle.

## Diagnostic synthétique

- Le headline actuel annonce un intitulé de poste sans domaine ni périmètre, il ne permet pas de comprendre la spécialité.
- La section About commence par une phrase générique, or les trois premières lignes seules sont visibles avant le repli.
- Les expériences décrivent des responsabilités sans effet mesurable.
- Les compétences déclarées ne reprennent pas le vocabulaire des offres visées.

## Headline, 3 variantes

Version sobre :

```text
Architecte IT, plateformes d'intégration et API management
```

Version expert :

```text
Architecte IT, intégration et API management, décommissionnement de socles legacy
```

Version exécutive :

```text
Architecte IT, je réduis le risque d'exploitation des socles d'intégration en grande entreprise
```

## About, version courte

```text
Architecte IT spécialisé sur les plateformes d'intégration et l'API management.
Je travaille sur des socles historiques à fort risque d'exploitation, avec des
trajectoires de migration progressives plutôt que des bascules uniques.

Dernier programme conduit : migration de 40 applications d'un ESB en fin de vie,
incidents majeurs réduits de 12 à 3 par an, mise à disposition d'une API ramenée
de 6 semaines à 5 jours.

Sujets sur lesquels j'échange volontiers : gouvernance d'API, réversibilité,
dette d'intégration.
```

## Expérience réécrite

Avant :

```text
Responsable de la plateforme d'intégration et des projets associés.
```

Après :

```text
- Piloté la migration de 40 applications vers une plateforme d'API management, équipe de 6 personnes sur 18 mois.
- Réduit les incidents majeurs de 12 à 3 par an.
- Défini la politique de gouvernance des API et le processus de mise en production.
```

## Compétences à prioriser

API management, architecture d’intégration, gouvernance des API, migration de legacy, conduite de programme technique.

## Justification des choix

- Le headline nomme le domaine, c’est lui qui pèse dans la recherche recruteur.
- La première ligne du About porte la spécialité, le reste est masqué par défaut.
- Chaque expérience contient un périmètre et un effet, condition de crédibilité pour un profil senior.
