# Quality checklist

## Exactitude

- Aucun chiffre, diplôme, certification, date ou périmètre inventé.
- Les hypothèses sont libellées comme hypothèses.
- Les informations manquantes sont marquées `[à compléter]` plutôt que devinées.

## Confidentialité

- Les noms de projets internes, clients, incidents et données sensibles sont anonymisés si diffusion publique.
- Les éléments contractuels ou stratégiques non publics sont retirés.

## Promesse

- L’abstract annonce un bénéfice pour l’auditeur, pas un plan de présentation.
- Le titre est compréhensible sans lire le résumé.
- Le niveau annoncé correspond au contenu décrit.
- Aucun contenu annoncé qui ne pourra pas être livré le jour du talk.

## Format

- Les longueurs imposées sont respectées, avec le compte de caractères indiqué.
- La biographie existe en version courte et version longue.
- Le plan est minuté et laisse une marge pour les questions.

## Neutralité

- Aucune perception promotionnelle pour un produit ou un employeur.
- Aucun client ou projet interne cité sans autorisation explicite.
- Les sources externes utilisées dans le talk sont identifiées.
