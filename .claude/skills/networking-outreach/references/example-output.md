# Exemple de sortie

Exemple fictif produit à des fins d’illustration. Les données ne correspondent à aucune personne ni organisation réelle.

## Contexte retenu

- Destinataire : responsable d’une équipe plateforme dans une entreprise cible.
- Lien réel fourni par l’utilisateur : a assisté à sa présentation lors d’un meetup, sujet identifié.
- Objectif : obtenir un échange informatif, pas une candidature.
- Canal : message LinkedIn, cible 60 à 100 mots.

## Message principal, 78 mots

```text
Bonjour [Prénom],

J'ai assisté à votre retour d'expérience sur le décommissionnement de votre ESB
au meetup [nom] en mars. Le point sur le double run prolongé m'a marqué,
j'ai conduit une migration comparable sur 40 applications et j'ai fait
le choix inverse.

Seriez-vous d'accord pour un échange de 20 minutes sur la façon dont vous
avez tranché ? Je comprendrais tout à fait que votre agenda ne le permette pas.

[Signature]
```

## Variante directe, 62 mots

```text
Bonjour [Prénom],

Votre retour d'expérience sur le décommissionnement de l'ESB au meetup [nom]
rejoint un programme que j'ai conduit sur 40 applications, avec un arbitrage
opposé sur le double run.

Auriez-vous 20 minutes pour en parler dans les deux prochaines semaines ?

[Signature]
```

## Variante prudente, 89 mots

```text
Bonjour [Prénom],

Je me permets de vous écrire suite à votre présentation au meetup [nom] en mars,
sur le décommissionnement de votre ESB.

Je travaille sur des sujets proches, une migration de 40 applications vers
une plateforme d'API management, et votre arbitrage sur le double run
m'a fait revoir certaines de mes hypothèses.

Si l'occasion se présente, je serais heureux d'échanger 20 minutes.
Sans réponse de votre part, je ne me permettrai pas d'insister.

[Signature]
```

## Note de demande de connexion, 264 caractères

```text
Bonjour [Prénom], j'ai assisté à votre retour d'expérience sur le décommissionnement
de votre ESB au meetup [nom]. J'ai conduit une migration comparable avec un arbitrage
opposé sur le double run. Je serais heureux d'échanger à l'occasion.
```

## Relance à J plus 10, 47 mots

```text
Bonjour [Prénom],

Je reviens brièvement vers vous. Nous venons de publier un retour interne sur
notre migration, je peux vous le partager si le sujet vous intéresse.

Si le moment n'est pas le bon, n'hésitez pas à ignorer ce message.

[Signature]
```

## Contrôles appliqués

| Point | Statut |
| --- | --- |
| Lien réel, non inventé | Meetup fourni par l’utilisateur |
| Demande unique | Échange de 20 minutes |
| Sortie honorable | Présente dans les trois variantes |
| Relance avec élément nouveau | Retour interne partagé |
